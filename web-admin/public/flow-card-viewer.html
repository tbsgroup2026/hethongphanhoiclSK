📌 Cách Sử Dụng

📥 Download SVG: Lưu file SVG gốc (có thể chỉnh sửa)
📸 Save as PNG: Browser sẽ render SVG thành PNG (high quality)
🖨️ Print: In hoặc lưu dưới dạng PDF

💡 Lưu ý: Để có PNG chất lượng cao nhất, hãy:
1. Click "Save as PNG" → Browser sẽ tải file PNG
2. Hoặc dùng browser DevTools (F12) → Right-click SVG → Save as image
3. Hoặc dùng Inkscape/ImageMagick (xem hướng dẫn dưới)

Để chuyển đổi SVG thành PNG:
✅ Method 1: Click "Save as PNG" ở trên
✅ Method 2 (Inkscape): inkscape public/flow-card-incident.svg --export-type=png -d 300
✅ Method 3 (Python): pip install cairosvg && python scripts/svg-to-png.py
✅ Method 4 (Online): https://cloudconvert.com/svg-to-png hoặc https://convertio.co/svg-png/
