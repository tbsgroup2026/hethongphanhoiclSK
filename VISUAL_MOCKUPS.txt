## 4. DESIGN SYSTEM COMPARISON

### SPACING
BEFORE: Hardcoded values (12px, 16px, etc.)
AFTER:  System constants (spacing.md, spacing.lg, etc.)

spacing.xs   =  4px
spacing.sm   =  8px
spacing.md   = 12px
spacing.lg   = 16px
spacing.xl   = 24px
spacing.xxl  = 32px
spacing.xxxl = 48px

### COLORS
BEFORE: Random hex values, no semantic meaning
AFTER:  Semantic palette:

Primary:      #005A36 (TBS Green - main accent)
Success:      #10B981 (Emerald - done status)
Warning:      #F59E0B (Amber - in progress)
Error:        #DC2626 (Red - urgent)
Info:         #0EA5E9 (Sky - investigating)
Text:         #0F172A (Dark slate)
Text Muted:   #94A3B8 (Light slate)
Border:       #E2E8F0 (Slate-200)

### RADIUS
BEFORE: Different values per component
AFTER:  Unified system:

radius.sm   =  8px (inputs, buttons)
radius.md   = 12px (cards)
radius.lg   = 16px (modals)
radius.full = 999px (pills)
